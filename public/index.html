如何选择符合心意的 IP？

本站特地为使用者将 IP 分为 4 类：

  • 数据中心：部署在机房、VPS 的 IP，速度通常十分可观，且可用性高，然而，某些风控严格的网站可能屏蔽来自数据中心的 IP。
  • 住宅家宽：这种 IP 通常声誉较高，就算被滥用，也大概率不会被拦截。然而，其网络速度可能稍慢，且容易跑路。
  • 教育网络：一种特殊的 IP，是分给各个学校（通常是大学）的专用 IP，声誉也较高，然而通常这类 proxyIP 可能具有试验性质，稳定性难以预料。
  • 移动网络：声誉也较高，但几乎找不到这类 proxyIP，且由于此类 IP 可能具有动态特性，最不稳定。
  • 商业网络：声誉较高，是各个商业性质的公司所拥有的 IP，比较罕见。
  • 政府网络：声誉高（哪个网站会拦截各国政府的 IP 呢），但此类 proxyIP 似乎比移动网络还罕见，因为此类 proxyIP 的存在，基本是因为政府人员的疏忽或设备的漏洞。

📖 什么是 ProxyIP？

ProxyIP 是一种用于 Cloudflare Workers 环境的反代 IP。

EDtunnel 以及其他类似项目通常部署在 Cloudflare Workers 上。然而，Cloudflare Workers 的 TCP sockets 文档 明确说明：

Outbound TCP sockets to Cloudflare IP ranges are blocked.

也就是说，Workers 会阻止指向 Cloudflare IP 段的出站 TCP 连接。 因此，部分依赖直连 Cloudflare CDN IP 的链路无法正常工作。

例如，部署在 Cloudflare Workers 上的 VLESS / Trojan 节点，在访问同样使用 Cloudflare CDN 的网站（例如 ipin.io、cloudflare.com、ip2location.com）时，可能会因为目标地址属于 Cloudflare IP 而受到限制。

ProxyIP 的作用，就是提供一个可用的中转地址，让 Workers 可以通过该地址访问 Cloudflare 服务。 部分 Cloudflare CDN VLESS 配置生成器中也将其称为“反代 IP”。

🚀 使用方式

1. 部署 EDtunnel

如果你还没有 EDtunnel，可以通过以下链接部署：

部署 EDtunnel 到 Cloudflare Workers

你也可以使用别人分享的 Worker，但建议使用自己的 Cloudflare 小号部署。

2. 修改 UUID

部署完成后，首先修改环境变量中的 UUID。

不要保留默认 UUID！

默认 UUID 很容易被扫描器发现，导致你的 Worker 变成公开节点，同时消耗 Cloudflare Workers 的每日访问额度。

3. 设置 ProxyIP

进入 Cloudflare Worker 的代码编辑页面，找到开头的 ProxyIP 数组。

可以修改为：（质量高） 

["proxyip.cmliussss.net:443"]

该方式相当于 fallback： 当你指定的 ProxyIP 不可用时，Worker 会自动尝试 ProxyIP 数组中的地址。

修改完成后记得点击部署。

4. 使用自定义域名

请务必给 Worker 绑定自定义域名。

由于 workers.dev 域名在部分地区（比如中国大陆）无法正常解析，直接使用 xxx.workers.dev 会导致无法连接。

若没有域名，你可以去 DNSHE 注册免费的 cc.cd、de5.net、cn.mt 域名，这些二级域名可以在 Cloudflare 当做顶级域名使用并配置。

5. 生成客户端配置

VLESS 配置格式示例： 

vless://UUID@你的域名:端口?encryption=none&security=tls&sni=你的域名&fp=random&type=ws&host=你的域名#ProxyIP

可用端口： 

443
8443
2053
2096
2083
2087

6. 设置 WebSocket Path

导入客户端后，在详细配置中修改 Path： 

/?ed=2048

7. 指定 ProxyIP

如果不指定 ProxyIP，将使用 Worker 默认配置。

你可以在 Path 后添加： 

/?ed=2048&proxyip=域名或IP:443

例如： 

/?ed=2048&proxyip=kz.proxyip.etoj.run.place:443

或者： 

/?ed=2048&proxyip=82.118.18.202:443

🔍 检查 ProxyIP 可用性

你可以使用 Check ProxyIP 检测域名或 IP 是否可用。

例如输入： 

kz.proxyip.etoj.run.place
82.118.18.202

如果检测成功，即可尝试使用。

⚠️ 使用注意

  • 请勿滥用 ProxyIP 或 Cloudflare Workers。
  • 不要公开传播自己的 Worker UUID。
  • Cloudflare 对其服务有使用限制，大规模滥用可能导致服务被限制或封禁。账号会被封（这就是为什么建议用小号）。
  • 建议合理使用，仅用于个人学习、测试和研究。
